# Reversa App Privacy Policy

Reversa App processes only the information the user provides in ChatGPT prompts or tool inputs, such as project name, stack, target engine, risk level, repository state, and constraints.

The app does not request API keys, passwords, source code, repository credentials, or account identifiers. The current MVP does not store user data, send user data to third-party services, or write to external systems.

Tool outputs may include generated checklists, workflow phases, and adoption plans derived from user-provided context.

If future versions add repository analysis, file upload, authentication, telemetry, or persistent storage, this policy must be updated before submission.
